# Georgina Ramos Portfolio

A professional portfolio website built with Next.js, TypeScript, and Tailwind CSS.

## Tech stack
- Next.js
- TypeScript
- Tailwind CSS
- ESLint

## Project goals
- Present a polished personal brand and experience
- Showcase featured projects and technical skills
- Provide a simple, modern contact path for opportunities

## Run locally
```bash
npm install
npm run dev
```

Then open http://localhost:3000 in your browser.

## Production build
```bash
npm run build
npm run start
```
